# IT Asset Tracking System 💻

A web-based IT Asset Tracking System developed to simplify the management, allocation, and monitoring of organizational IT assets.

## 🎯 Project Overview
This project was developed as part of my BCA academic journey at Hirachand Nemchand College of Commerce, Solapur.

## 🚀 Key Features
- Admin and Employee Login
- Asset Management
- Employee Management
- Asset Assignment and Tracking
- Asset Requests and Returns
- Notifications and Reports

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL / MariaDB
- Development Tools: VS Code, XAMPP
