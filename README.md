💻 IT Asset Tracking System

Web-Based IT Asset Management Application

A full-stack web application developed to manage, monitor, and track organizational IT assets efficiently.

📌 Project Overview

The IT Asset Tracking System is an academic project developed as part of my Bachelor of Computer Applications (BCA) journey at Hirachand Nemchand College of Commerce, Solapur.

The system simplifies asset management through separate Admin and Employee interfaces, providing a structured way to manage assets, employees, assignments, requests, and reports.

🚀 Key Features

* 🔐 Admin and Employee Authentication
* 📊 Interactive Admin Dashboard
* 💻 Add, Edit, View, and Manage IT Assets
* 👥 Employee Management
* 📋 Asset Request and Approval Management
* 🔄 Asset Assignment and Return Tracking
* 🔔 Employee Notifications
* 📈 Asset Reports and Tracking
* 🎨 User-Friendly Interface

⚙️ How to Run the Project

1. Install XAMPP.
2. Download or clone this repository.
3. Place the project folder inside xampp/htdocs.
4. Start Apache and MySQL from XAMPP.
5. Create the it_asset_tracking database in phpMyAdmin.
6. Import the project’s database schema when available.
7. Configure the database connection and credentials for your local environment.
8. Open the application through http://localhost/IT-Asset-Tracking/, using your actual project folder name.

Note: The application requires a configured PHP/MySQL environment and the appropriate database tables.
